# Personal Portfolio

Modern responsive portfolio built with **React (JavaScript)**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## Sections

- Sticky navbar with mobile menu + dark/light theme toggle
- Hero with entry animations
- About, Education timeline, Tech Stack filters, Projects filters
- Contact form with validation (mailto) + social links

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Customize content

Edit `src/data/portfolio.js` to update your name, bio, education, skills, projects, and social links.

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Production build         |
| `npm run preview` | Preview production build |
